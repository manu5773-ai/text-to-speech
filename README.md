# Voxa — Text to Speech

Open index.html in a modern browser. No installation or API key required.

Includes HTML, CSS, and JavaScript in one file. Uses browser speechSynthesis; available voices depend on your browser and device. Features voice/language selection, text-file import, speed/pitch adjustment, and playback controls.

## GitHub
Upload index.html and this README.md to your repository. To host, enable Settings > Pages > Deploy from a branch > main > / (root).
